# 🐍 Python Programs – Core Concepts Explained

This repository contains **well-structured and descriptive Python programs** created to understand the **core concepts of the Python programming language** from basics to intermediate level.

The code is written in a **simple, readable, and beginner-friendly manner**, with proper comments and explanations, making it useful for:
- Beginners learning Python
- Interview preparation
- Teaching Python fundamentals
- Revision of core concepts

---

## 📌 Topics Covered

- Python Overview & Syntax
- Variables and Assignment
- Data Types
  - int, float
  - string
  - list, tuple
  - dictionary, set
- Operators
- Control Flow Statements
  - if / else
  - loops (for, while)
- Functions
- Lambda funtion
- Programming paradigms
- Functional Arguments
- Filter, Map, Reduce (FMR) concept
- Modules & Packages (basics)
- Object-Oriented Programming (OOP)
  - class & object
  - constructor
  - inheritance (basics)
